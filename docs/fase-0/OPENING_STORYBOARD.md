## Onboarding dan tindakan pertama
1. Landing → prolog → penerimaan (skip langsung ke penerimaan). Sesudah login gunakan progres server untuk lanjut. Akun lama dapat memutar ulang dari Jurnal tanpa hadiah.
2. Daftar/login dengan pemeriksaan usia yang ditinjau dan dua opsi gender §7g. UI menjelaskan penggunaan atribut privat. Jika belum memenuhi persyaratan usia/izin, hentikan pembuatan state ekonomi. Pilih Indonesia lalu kota/kabupaten manual; tanpa GPS atau alamat.
3. Pilih nama karakter, filter dan tangani konflik nama tanpa mengulang kota. Satu transaksi membuat lahan 100 m², 10.000 Gaia Coin, gerobak, gudang, pemilahan, Awaken, Karma 0 [U]. Simpan langkah dan versi onboarding, intro_seen_at, city_id, tutorial_completed_at. Refresh saat transaksi mengembalikan starter yang sama.
4. Target waktu setelah setup: 0–30 detik ketuk Angkut dan pilih kontrak kecil yang menampilkan fraksi/biaya. 30–60 detik ambil lalu ketuk Pilah. 60–100 detik lihat dua tumpukan dan pilih Jual bahan terpilah atau titip proses kompos tutorial [R]. 100–150 detik konfirmasi, bandingkan saldo, massa dan sisa. Penjualan bahan terpilah memungkinkan starter beroperasi dengan satu mesin. Mesin termal terbuka sesudah misi konsekuensi. Penjelasan rinci muncul saat pemain menyentuh sisa material. Tidak ada kuis.
5. Layar rutin: header koin/tier/Karma/status, pabrik 2D dan panel ketuk, pesan Gaia, tombol Neraca Massa dan BHI. Navigasi Pabrik, Angkut, Pasar, Kota, Bumi; daftar setara tanpa drag. Kota/Bumi menampilkan status fase yang jujur.
6. Urutan bab internal: The Cry of Earth → The Calling of Gaia → The Genesis → The Illusion of Waste (sisa pertama) → The Cycle of Matter (neraca ditutup) → The Rise of Guardians (misi kota) → The Alchemy of Gaia (gate lab) → The Rebirth of Earth (upacara). Bab dan lima tahap fasilitas dari gerobak sampai Zero Waste Civilization masing-masing punya pemicu sendiri.

Uji UI 360 px, pembesaran teks, fokus keyboard, target sentuh [U] 44 px, kontras dan petunjuk ikon+teks. Mode gerak rendah mengganti kamera dengan pergantian panel. Muat adegan pertama, prefetch satu berikutnya, lepaskan gambar/audio terdahulu. Tombol mute, volume, subtitle, ulang dan lanjut tetap berfungsi ketika codec atau jaringan gagal.

## Penambahan Kebun Gaia

Starter menambahkan kantong benih dari Gaia (2 kangkung + 1 bayam). Aksi tanam bersifat opsional; saat kompos pertama tersedia, perlihatkan pilihan jual/pupuk. Dialog dan urutan lengkap di KEBUN_GAIA.md.

## Penyelarasan Alur Layar (DESIGN_SPEC v1.3 §2, §5, §14, §17)
Urutan layar onboarding yang diselaraskan:
1. **Landing** (gaya eco-fantasy hijau-emas; tidak memuat renderer pabrik) → **Prolog** (fakta dunia bersumber → upaya global/lokal → panggilan Gaia → misi; tombol lanjut, kembali, lewati, subtitle, mute).
2. **Pilih Karakter** (dua kartu pria/wanita, kemampuan & ekonomi identik) → **Buat Profil** (nama karakter + pilihan ID kosmetik rambut, pakaian, topi, kacamata, tas, aksesori; tombol acak gaya).
3. **Pilih Kota** (negara/provinsi/kota-kabupaten manual + pencarian, tanpa GPS) → **Mulai Misi** (ringkasan starter: 10.000 Gaia Coin, 100 m², 1 gerobak, 1 gudang, 1 area pilah, Awaken, Karma 0%, 3 benih) → **Pabrik**.
4. **Tutorial hari pertama (DWE + DLE):** Avatar mulai di akses gerbang aman. Gaia menunjuk gerbang → buka **Angkut** → pilih sumber Permukiman/Pasar → kirim gerobak → terima → pilah → olah/jual → cek Neraca Massa. Jika insiden tutorial DLE muncul di bahu jalan/tepi sungai, Gaia memandu: *“Ada sayuran tercecer di depan gerbangmu. Bersihkan jalan dan manfaatkan bahan organiknya.”* Target aksi bermakna pertama tetap ≤3 menit tanpa forced wait. Kebun Gaia menjadi misi lanjutan setelah kompos tersedia.
