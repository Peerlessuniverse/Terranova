## E. Provenance dan pengkinian

Seed ini merupakan normalisasi rentang pada daftar harga percakapan sebelumnya dan asumsi tambahan untuk kebutuhan game. Tidak ada verifikasi transaksi November 2026 pada penyusunan file ini. Referensi kandidat untuk riset kalibrasi: bank sampah daerah (Jalatrang, DKI, Faperta Unmul), pengepul lokal, Surya Indo Utama, pemasok bijih plastik Bandung, Indotrading, LME. Sebelum label harga nyata digunakan, simpan URL/quotation, tanggal observasi, wilayah, unit, grade, basis pajak/angkut, sample size dan status verifikasi. Default seluruh row = SIM_ESTIMATE; angka khusus logam mulia, elektronika, energi dan produk olahan = LOW confidence. Harga skenario tidak diklaim sebagai statistik nasional.
