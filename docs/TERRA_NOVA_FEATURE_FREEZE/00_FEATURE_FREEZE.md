## Decision register
- K1: Bandung default lokal; pilihan kota manual setelah tutorial sebelum kontrak kota resmi beta. K2: karakter pria/wanita aktif; kosmetik tambahan setelah loop stabil. K3: usia, privasi, consent dan review hukum sebelum publik; metode belum diputus. K4: replay opening dari Menu tanpa grant. K5: Realistic Economy target tunggal; 1 juta GC konfigurasi uji utama, 100 ribu pembanding; bukan migrasi saldo otomatis. K6: ledger resmi semua spawn termasuk sungai sebelum kredit online. K7: optimasi aset dahulu, siklus empat arah kemudian; tidak ada pengeluaran baru otomatis. Rekomendasi K1–K7 sebelumnya diterima secara arah, rincian masih [U/R].
- Prolog 120 detik, Eric Dipoetra, Gaia reference pertama, onboarding saat ini tetap; twist tidak dibocorkan. 500 kg gudang, 3 benih (2 kangkung, 1 bayam sebagai seed uji), gerobak, area pilah, lahan berantakan. Nav Pabrik/Kebun/Angkut/Pasar/Menu.
- DRES rumah tangga–UMKM; 100 kW/200 kWh parameter uji, bukan batas total industri WtE. Semua katalog edukasi, mesin berisiko/eksperimental terkunci. Tidak membuat pembangkit energi abadi.
- God: GSG, bukan kekayaan/400k XP; jalur kecil dan industri setara. 03 tier XP historis, 11 GT01–09 target aksi [U]; tidak menumpuk kedua gate. Hidden gem dan upacara global terpisah, aturan lama perlu review termasuk hadiah 18+; default beta penghormatan netral usia. Chosen kandidat God, tanpa pabrik besar, kekayaan tidak melebihi 1 miliar GC, WtE rumah tangga + energi alam, konsistensi tonase. Definisi peak, periode dan seleksi akhir tetap U; jangan aktifkan penghargaan otomatis.
- Pay to Build, Play to Achieve: top-up mempercepat ekonomi, tidak membeli God/badge/score; bukan klaim kompetisi ekonomi sepenuhnya bebas pay advantage. Self-Made track; donasi tidak memberi keuntungan. Tidak ada cash-out, loot box berbayar, blockchain.
- 10 rekomendasi terakhir: event, pemulihan ekonomi, pasar bekas, knowledge center, error actionable, waktu bermain sehat, admin, feedback, keamanan/privasi, Chosen tertunda. Semua masuk scope bertahap.

## Quality gates
G0 audit repo, conflict log, backup, seed validation. G1 ekonomi dan mass ledger, G2 pasar/angkut, G3 pangan/vitalitas, G4 GSG dan misi, G5 visual/asset, G6 audio/celebration/support/admin, G7 regression dan simulasi. Beta hanya jika funding dan security/legal/privacy/payment review serta load test disetujui. Tidak menganggap scope freeze sebagai bukti pengujian. Tidak ada pembelian server atau aset otomatis.
